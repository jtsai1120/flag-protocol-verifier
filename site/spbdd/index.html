C++17 with SPBDD, run by an interpreter in your browser. Each example also compiles with g++ -std=c++17 prog.cpp libspbdd.a and prints the same. Ctrl+Enter runs.

API reference

Everything is in namespace spbdd. Only one context can be alive at a time; it is destroyed when it goes out of scope.

context ctx(n);n qubits. context ctx(data, ancillas); puts data qubits first.
ctx.empty() all() identity()The empty set, all 4n Paulis, {I…I}.
ctx.from_str("XZI")One Pauli. from_list({...}) for several.
ctx.generated_by({...})The group the Paulis generate (phases ignored).
ctx.coset_of(base, {...})base · ⟨generators⟩; the second argument may also be a pset.
ctx.matching("X*Z")Every Pauli matching the pattern; * is any of I, X, Y, Z.
ctx.pauli_at(q, 'X')Every Pauli with X on qubit q.
ctx.weight_at_most(w)Also weight_exactly(w), weight_between(lo, hi), each with an optional list of qubits.
ctx.identity_on({q…})Every Pauli that is I on those qubits.
ctx.commute_with("XZ")Every Pauli commuting with it (or with each of a list).
a | b, a & b, a - b, a ^ b, ~aUnion, intersection, difference, symmetric difference, complement; also |= and the rest.
a * bSetwise product {pq : p ∈ a, q ∈ b}.
a == b, a.subset_of(b)Constant time: the diagrams are canonical.
a.size() a.node_count()Elements (a double), and BDD nodes.
a.contains("XZ") a.is_empty()Membership and emptiness.
a.for_each_element(f)Calls f(const std::string&) per element until it returns false.
a.any_element()A std::optional<std::string>.
a.h(q) s sdg sx sxdg x y zSingle-qubit Cliffords, in place; they return pset&, so they chain.
a.cx(c, t) cy cz swapTwo-qubit Cliffords, in place.
a.fault_inject({q…})a · (every Pauli on those qubits): one fault there.
a.measure_z(q)A meas_result {meas_0, meas_1}: the parts that commute and anticommute with Zq. measure_z(q, outcome) gives one part. Also measure_x, measure_y.
a.reset({q…})Clear those qubits to I, in place.
code c(ctx, gens, d);A stabilizer code on the data qubits; d is optional.
c.n() k() r() d()Parameters.
c.S() N() NmS()Stabilizer group, normalizer, non-trivial logicals N(S)−S.
c.logical_X_operators()Also logical_Z_operators(), stabilizer_generators().
c.syndrome_of("XIIII")A std::vector<bool>. Also logical_component_of.
c.by_syndrome({…})Every Pauli with that syndrome. Also by_logical_component.
c.find_qec_cond_violation(E, m)Two errors in E with the same syndrome whose product is in N(S)−S, as std::optional<std::pair<std::string, std::string>>. m is code::fqcv_method::bruteforce, table, image (the default) or square.
What C++ the playground runs

A subset of C++17, interpreted:

  • free functions (no overloading), lambdas, global and local variables, using aliases;
  • if/else (with an initializer declaration), for, range-for, while, do, break, continue, return, structured bindings of std::pair and meas_result;
  • bool, char, the integer types, double, std::string, std::vector, std::pair, std::optional, and SPBDD's context, pset, code, meas_result;
  • std::cout with std::endl, std::setw, std::setprecision, std::fixed, std::boolalpha; std::to_string, std::min, std::max, static_cast.

Not supported: struct and class, templates of your own, pointers, exceptions, and the rest of the standard library, such as std::map.

One extension: std::cout << s prints a pset as {A, B, …} (its first 32 elements) and a std::vector as [a, b, …]. Real C++ needs a loop for that, as in the examples.
