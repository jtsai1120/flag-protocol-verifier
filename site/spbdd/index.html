API reference

Names follow the C++ library. Operators become methods; gates change the set in place and return it, so they chain. Only one context can be alive at a time: call ctx.delete() before making another.

new spbdd.Context(n)n qubits. new spbdd.Context(data, ancillas) puts data qubits first.
ctx.empty() all() identity()The empty set, all 4n Paulis, {I…I}.
ctx.from_str('XZI')One Pauli. from_list([...]) for several.
ctx.generated_by([...])The group generated by the given Paulis (phases ignored).
ctx.coset_of(base, [...])base · ⟨generators⟩.
ctx.matching('X*Z')Every Pauli matching the pattern; * is any of I, X, Y, Z.
ctx.pauli_at(q, 'X')Every Pauli with X on qubit q.
ctx.weight_at_most(w)Also weight_exactly, weight_between(lo, hi), and …_on(w, qubits).
ctx.commute_with(p)Every Pauli commuting with p (or with each of an array).
a.union(b) intersect minus xor|, &, −, ^. a.complement() is ~a.
a.mul(b)Setwise product {pq : p ∈ a, q ∈ b}.
a.equals(b) subset_of(b)Constant time: the diagrams are canonical.
a.size() node_count()Elements, and BDD nodes.
a.contains('XZ') is_empty()Membership and emptiness.
a.elements(limit)Elements as strings; printing a set shows the first 32.
a.h(q) s sdg sx sxdg x y zSingle-qubit Cliffords, in place.
a.cx(c, t) cy cz swapTwo-qubit Cliffords, in place.
a.fault_inject([q…])a · (every Pauli on those qubits): one fault there.
a.measure_z(q){meas_0, meas_1}: the parts that commute and anticommute with Zq. measure_z(q, 1) gives one part. Also measure_x, measure_y.
a.reset([q…])Clear those qubits to I, in place.
a.clone()A copy, for when a gate should not touch the original.
new spbdd.Code(ctx, gens, d)A stabilizer code on the data qubits; d is optional.
code.n() k() r() d()Parameters.
code.S() N() NmS()Stabilizer group, normalizer, non-trivial logicals N(S)−S.
code.logical_X_operators()Also logical_Z_operators(), stabilizer_generators().
code.syndrome_of('XIIII')As a bit string. logical_component_of likewise.
code.by_syndrome('1000')Every Pauli with that syndrome. Also by_logical_component.
code.find_qec_cond_violation(E, m)Two errors in E with the same syndrome whose product is in N(S)−S, as [e1, e2], or null. m is 'bruteforce', 'table', 'image' (default) or 'square'.
